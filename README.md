## Experiments

### 1. **Agglomerative Clustering** (`AglomerativeClustering.ipynb`)
Implementation of hierarchical agglomerative clustering algorithm. This experiment demonstrates bottom-up clustering approach where each data point starts as a separate cluster and is progressively merged based on proximity metrics.

### 2. **Decision Tree Classification** (`DecisionTree - Copy.ipynb`)
Explores decision tree algorithms for classification tasks. Covers tree construction, pruning techniques, and evaluation metrics to understand how trees make splits based on feature importance.

### 3. **K-Means Clustering** (`KMean.ipynb`)
Implementation and analysis of the K-Means clustering algorithm. Demonstrates centroid-based partitioning, convergence behavior, and optimal cluster selection using methods like the elbow method.

### 4. **K-Medoid Clustering** (`K-Medoid.ipynb`)
Advanced clustering technique using medoids (actual data points) instead of centroids. This method is more robust to outliers compared to K-Means clustering.

### 5. **IML Day 1 Experiment** (`IML_DAY1.ipynb`)
Foundational machine learning concepts and introductory algorithms covered on the first day of the course.

### 6. **IML Day 2 Experiment 2** (`IML_DAY2_exp2.ipynb`)
Continuation of machine learning concepts and practical implementations from day 2, experiment 2.

### 7. **IML Experiment 3** (`IML_expt_3.ipynb`)
Intermediate machine learning concepts and advanced algorithmic approaches.

### 8. **IML Experiment 4** (`expt4.ipynb`)
Fourth formal experiment covering additional machine learning techniques and applications.

### 9. **IML Experiment 5** (`IML_EXPT_5.ipynb`)
Comprehensive experiment covering advanced topics and integration of multiple machine learning approaches.
